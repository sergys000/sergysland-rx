Новые функции SergysLand

1. Замените файлы сайта файлами из этой папки (или загрузите обновлённую папку проекта в GitHub).
2. В Supabase откройте SQL Editor и выполните ПОЛНОСТЬЮ обновлённый файл supabase.sql. Он создаёт таблицы заявок и медиагалереи, функции сохранения IP и серверную цензуру отзывов. Перед выполнением сохраните резервную копию базы.
3. Заявки: раздел «Заявка в команду». Одна заявка на IP. Персонал может менять статус и удалять заявки; очистка всех заявок доступна администратору.
4. Чаты: кнопка «Очистить все чаты» находится в панели разработчика. Удаление необратимо.
5. Медиа: в панели разработчика → «Медиа» добавляйте публичные URL изображений или видео (сайт не загружает сами файлы, он хранит ссылки). Только администратор может добавлять/удалять материалы.
6. Twitch: встроенный плеер показывает текущий эфир. Прошлые записи доступны кнопкой «Архив прошлых стримов». Twitch требует параметр parent с доменом сайта; в проекте указан sergys000.github.io. Если сайт открывается на другом домене, замените parent в iframe на фактический hostname.
7. IP-адреса обрабатываются серверной функцией Supabase по заголовкам запроса. Если инфраструктура не передаёт IP в заголовках, форма сообщит, что определить IP не удалось. Не храните IP дольше, чем нужно для модерации; используйте HTTPS и сообщите посетителям об обработке IP в политике конфиденциальности.
8. Цензура отзывов — базовый список слов, который можно изменить в функции censor_review_text() в supabase.sql. Это не заменяет ручную модерацию.

Важно: изменения интерфейса не применятся к опубликованному GitHub Pages, пока вы не загрузите файлы в репозиторий. Не публикуйте service_role key; используйте только publishable key и политики RLS.
